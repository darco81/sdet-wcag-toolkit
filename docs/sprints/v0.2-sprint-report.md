# Sprint 2 report - v0.2.0 Mid (static + dynamic + reports)

Dates (calendar): 2026-01-15 → 2026-02-28
Release: v0.2.0 (2026-02-28) - **last public release**

## What landed

### New packages

- **`@sdet-wcag-toolkit/dynamic-tester`** - Playwright-driven audit
  pipeline:
  - `BrowserManager` - owns the browser lifecycle (chromium/firefox/webkit)
  - `AxeRunner` - wraps `@axe-core/playwright`, maps violations to
    `WcagFinding` (55-SC catalog aware, skips best-practice-only rules)
  - `KeyboardFlowRunner` - positive-tabindex in rendered DOM, Tab cycle
    sanity, Escape-closes-dialog
  - `FocusVisibilityRunner` - computed outline/box-shadow/border check
    per keyboard-focused element
  - `DynamicTesterOrchestrator` with `createDefaultDynamicOrchestrator`
    factory mirroring the static path's ergonomics.

- **`@sdet-wcag-toolkit/reporter`** - markdown generators:
  - `formatDevReport` - long-form, severity table, top-N priority list,
    findings grouped by WCAG principle, SC refs, remediation, snippets.
  - `formatExecSummary` - one-pager, user-impact language, EAA/legal
    context, 60-line hard cap.

### CLI

- `wcag-toolkit audit` accepts `--url <url>` for dynamic runs and
  `./path --url <url>` for the full combined audit. `--wait-for
  <selector>` for SPA hydration. Combined mode dedups findings by id.
- `wcag-toolkit report --from findings.json --format dev|exec` - format
  a previously-saved findings JSON. `--output` writes to a file.

### Claude Code

- 7 new agents: `forms-accessibility-agent`, `wcag-dynamic-lead`,
  `axe-runner-agent`, `keyboard-flow-agent`, `focus-visibility-agent`,
  `dev-report-agent`, `exec-summary-agent`. Total now 12.
- 2 new skills: `wcag-dynamic-test`, `wcag-report`.
- 3 new commands: `/wcag:audit:dynamic`, `/wcag:audit` (full pipeline),
  `/wcag:report`.

### Docs

- `docs/WCAG-COVERAGE.md` - every SC in WCAG 2.2 A+AA with static /
  dynamic / manual coverage columns. Honest about the ~40% of SCs that
  require manual review.
- README rewritten around v0.2 scope plus explicit **commercial gate**:
  v0.3+ (self-fix) is a service, not an open-source release.

readers self-qualify.

## Known limitations (v0.2)

- **Single-page dynamic audits.** Multi-page crawls wait for v0.3+.
- **No auth flow support in dynamic mode.** The browser starts fresh
  every run. Tokens/cookies must be injected manually if needed.
- **`--wait-for` is a CSS selector only.** More complex settle conditions
  (network-idle variants, custom predicates) need manual scripting.
- **Focus-visibility uses computed styles, not screenshots.** Sufficient
  for 2.4.7 but not for visual regression of focus rings; that's a
  separate v0.3 feature.
