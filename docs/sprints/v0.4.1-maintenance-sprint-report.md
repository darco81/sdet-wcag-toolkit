### Coverage delta highlights

- **Multi-page orchestrator cleanup contract** (`+10` cumulative
  across phases 2 + 7) - the cleanup hook is invoked on success,
  on empty discovery, on auditPage rejection, and is bounded by
  `cleanupTimeoutMs` so a hung `browser.close()` cannot block the
  CLI process.
- **Sitemap edge cases** (`+7`) - empty urlset, sitemap index
  pointing at empty children, `<url>` without `<loc>`,
  percent-encoded paths, port-mismatch rejection, 120-child index
  expansion, seen-set cycle protection independent of `maxDepth`.
- **Router-scan detectors** (`+11`) - Next.js optional catch-all
  `[[...rest]]`, `not-found.tsx` / `default.tsx` / nested route
  groups, App-Router-only-API returns `[]`, Astro deeply-nested
  dynamics, Vue catch-all `[...path]` and walker-level extension
  filtering.
- **Dispatcher** (`+6`) - exhausted-fallback warning aggregation,
  missing-strategy throw, max-pages cap on dispatched result.
- **Cross-page dedup** (`+4`) - duplicate-on-same-page handling,
  affectedPages lexicographic sort, distinct-selector grouping,
  `auditedUrl` vs. `discoveredRoute.path` fallback.
- **Reporters** (`+8`) - markdown rendering on empty/skipped-only
  reports, console rendering with three skip reasons grouped.

## Backwards compatibility

`v0.4.1` keeps the public API of v0.4.0 byte-identical. No exported
type, function, or CLI flag changed signature. New optional fields
(`MultiPageAuditOptions.cleanup`, `cleanupTimeoutMs`) default to
behaviour that matches v0.4.0 semantics - the orchestrator now
*also* cleans up the browser, where v0.4.0 silently leaked it.

The v0.3 → v0.4 backwards-compat invariant ("running without
`--multi-page` is byte-identical to v0.3") is unchanged.
