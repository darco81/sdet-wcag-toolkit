# sdet-wcag-toolkit

WCAG 2.2 AA accessibility toolkit for modern web applications.

> Status: early scaffolding. Check back soon.

## Goals

A pragmatic toolkit for engineers who need to bake accessibility into their
pipeline rather than treat it as an afterthought:

- **Static analysis** of source code (JSX, HTML, CSS) for WCAG 2.2 AA issues
- **Dynamic testing** via Playwright + axe-core for browser-runtime violations
- **Actionable reports** for both developers and non-technical stakeholders

Built for a multi-agent workflow (Claude Code), but the CLI works standalone.
